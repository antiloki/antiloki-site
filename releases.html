2. Install

  • Windows: run the .exe. The installer is not code-signed yet, so Windows may show a SmartScreen warning: choose More info, then Run anyway.
  • Linux: sudo apt install ./antiloki_<version>_amd64.deb (or install the .deb with your distribution's tool), then start antiloki from your launcher.
  • First start: the app opens a window and its setup guide checks which AI tools you have. The 14-day trial starts on the first run and makes no network check.
  • Licence: one payment, a licence key by email, entered once in the app. See the terms and the privacy policy.
