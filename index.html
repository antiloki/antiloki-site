What is antiloki?

A free vibe graphing IDE. You describe the work in plain words, the Leader drafts a team as a graph of agents, tools, checks and gates, you edit it on the board, and the loop runs it on the AI subscriptions you already have. Antiloki is also an MCP server, so the tools you use can drive its threads, sagas, X-ray and teams.

What is vibe graphing?

Describing the work in plain words and getting a graph back: the Leader drafts a team as nodes and edges (agents, tools, forks and joins, checks, loops, gates), you edit it on the board, and the loop runs it under the budget you set. Every node is visible while it works and is recorded afterwards, so the graph is both the plan and the proof of what ran.

What are the nodes of a graph?

A graph is built from nodes you can see, edit and run: the Leader (your terminal agent, exactly one per graph); agents (a planner, worker, QA, debugger, audit, or your own agent with its own brief and tools); tools (web search and page reading, and this app's own tools, each with an allow-list); fork and join to run branches side by side; if and switch to route on a result; loops with a max count and a cost cap; for-each, retry, a human gate that waits for your yes or no, artifacts (documents the run makes) and deliver.

How does a run stay within budget?

Every loop needs a max count and a cost cap, and any node can carry its own cost cap. A run is stopped when it reaches its budget. Every node records its agent, exact model, time and cost, in order, on the saga.

What are teams?

A team is a graph you draw and edit. The Leader designs it with you, a driver runs it node by node, and each run leaves artifacts (documents the next node reads and you can open). Agents can propose changes to their skills, but as drafts: nothing changes until you approve it.

Is antiloki an MCP server?

Yes. An MCP client such as Claude Code can open threads and panes, read and add sagas, rebuild and open the X-ray, and design and run teams through antiloki's MCP tools (for example antiloki_team_design, antiloki_sagas and antiloki_xray). A node in a graph can use only the tools it names.

What is the Cowork screen?

Your agents' real terminals, side by side in panes, with the Leader and the team's graph beside them. Web apps open in their own pane from a store. Threads give each line of work its own git branch and worktree, so agents can work on different things at once and land them when you say.

What are Sagas?

A list per project of goals, tasks and their runs. A saga keeps who did each step, the exact model, the time and the cost, and a finished saga stays on the record.

What is the X-ray?

The X-ray is a health view of your repo: a verdict row (health, risk, coverage, solo-owned files, vulnerable dependencies), health over time, hotspots by gravity and churn, a codebase map that colours every file by the lens you pick (health, cascade, ownership, debt, heat or runtime coverage), the laws broken most, and what moved since the last snapshot. The chat sees all of it, so "why is this file 81?" gets a real answer.

Are web apps supported?

Yes. Web apps open in their own pane from a store, next to your agents. A graph can also use the web node, which searches the web and reads a page for the agent that asked.

Is it really free? What is the catch?

There is no catch in antiloki: no paid tier, no trial that ends, no account. The only costs are the model subscriptions or API keys you choose to use, and those are billed by their vendors. We plan to publish the source, so you can check that nothing is hidden.

Does it replace Claude Code, Codex, Cursor, Gemini or Grok?

No — it runs them, twice over: as the agent in its box, and as the engine behind antiloki's own AI (the chat, the reviews, the ultra review), each through its own vendor CLI. Keep your subscriptions; there is no API key to paste.

Can an agent change my files without asking?

No. An agent can only write inside the folders its node is allowed to touch. Anything that leaves the project, such as a commit to your branch or a publish, waits at a gate for your yes or no.

Do I need two subscriptions?

No. One subscription is enough: antiloki runs on whichever CLI you are signed in to. A team can use more than one seat, a planner on one and workers on another, if you have them. It only offers a provider you are actually signed in to: it reads the seat, not the installed binary.

Isn't this just worktrees and tmux?

Worktrees are the easy part. The fence enforced where the work lands, the gate before anything leaves the project, the sagas that keep the record, the X-ray that knows the repo, and the cost-per-run record are what you can't script in an afternoon.

Can my company install it?

One binary, local, no account, no telemetry. The network calls are: your CLIs' own calls; an update check against a static file on GitHub Releases; the window's fonts, fetched from Google Fonts (fonts.googleapis.com and fonts.gstatic.com) when it opens; api.openai.com or openrouter.ai only if you set up the optional OpenCode route with your own key; and GitHub only if you add a token or open a pull request. Send that to security.
