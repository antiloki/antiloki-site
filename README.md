# antiloki-site

The website and documentation of **[antiloki](https://github.com/antiloki/antiloki)**, a free and open-source vibe graphing IDE (Apache-2.0).

- 🌐 Site: <https://antiloki.com>
- 📖 Documentation: <https://antiloki.com/docs.html>
- ⬇️ Downloads: [antiloki-releases](https://github.com/antiloki/antiloki-releases/releases)
- 🧩 Source of the app: [antiloki/antiloki](https://github.com/antiloki/antiloki) and [antiloki/antiloki-ui](https://github.com/antiloki/antiloki-ui)

This repository holds the **published** pages only (static HTML served by GitHub Pages). To suggest a fix to the documentation, open an issue in [antiloki/antiloki](https://github.com/antiloki/antiloki/issues).

The app's code is Apache-2.0; the text and images of this site are © the antiloki authors.
